# Machine Learning

Welcome to my **Machine Learning** repository.

This repository contains my hands-on experiments and practical implementations while learning **Python, Data Analysis, Data Preprocessing, and Machine Learning fundamentals**.

The experiments are implemented using **Jupyter Notebook** and Python libraries such as Pandas, NumPy, Matplotlib, Seaborn, and Scikit-learn.

---

## 📚 Experiments

### 🔹 Experiment 1 — Employee Dataset

**Objective:**
Perform data cleaning, preprocessing, and exploratory analysis on an Employee dataset.

**Dataset Information:**

* 148 initial records
* 6 columns
* Company
* Age
* Salary
* Place
* Country
* Gender

**Topics Covered:**

* Loading CSV data using Pandas
* Checking dataset shape
* Removing duplicate records
* Resetting DataFrame index
* Inspecting dataset information
* Detecting missing values
* Finding unique values
* Cleaning inconsistent company names
* Cleaning inconsistent place names
* Descriptive statistics
* Data preprocessing

The experiment starts with an Employee dataset containing 148 rows and 6 columns. Duplicate analysis identified 4 duplicate records, after which the dataset was reduced to 144 records.
📓 **[Open Experiment 1](./Exp1/Exp1.ipynb)**
